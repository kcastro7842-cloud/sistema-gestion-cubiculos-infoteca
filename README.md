# Sistema de Gestión de Cubículos
## Infoteca Campus Arteaga

### Descripción del proyecto
Proyecto académico enfocado en el diseño y desarrollo de un sistema web para apoyar la gestión y reservación de cubículos de estudio de la Infoteca Campus Arteaga.

### Objetivo general
Desarrollar un sistema que facilite la consulta de disponibilidad y la administración de reservaciones de cubículos.

### Objetivos específicos
- Identificar los requerimientos del sistema.
- Diseñar la estructura y funcionamiento del sistema.
- Desarrollar las funcionalidades acordadas por el equipo.
- Realizar pruebas para verificar su funcionamiento.

### Funcionalidades propuestas
- Consulta de cubículos disponibles.
- Solicitud de reservaciones.
- Consulta de reservaciones.
- Administración de horarios y disponibilidad.

### Organización del repositorio
- documentacion: documentación del proyecto.
- diagramas: diagramas y modelos del sistema.
- codigo: archivos del sistema.
- pruebas: pruebas y evidencias.

### Estado del proyecto
En desarrollo. Los requerimientos y las tecnologías se encuentran sujetos a revisión por el equipo.
