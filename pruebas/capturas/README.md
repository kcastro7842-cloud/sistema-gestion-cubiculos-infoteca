# Evidencias visuales del sistema

Esta carpeta contiene las capturas de pantalla del Sistema de Gestión de Cubículos de la Infoteca Campus Arteaga.

## Contenido
- Entorno de desarrollo y ejecución del servidor.
- Creación y consulta de la base de datos.
- Pantalla principal y disponibilidad de cubículos.
- Formulario y confirmación de reservaciones.
- Generación de códigos QR.
- Historial de reservaciones.
- Registro de entrada y salida.
- Consulta de reservaciones canceladas.
